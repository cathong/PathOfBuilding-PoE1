# PoE 1 3.30 本地预览

分支为 `local/poe-3.30`，从本机中文版源码 `4d0ea9113` 分出。角色天赋树使用 GGG 的 3.30.0 预览导出。PoB 的应用版本号仍为 2.67.2，角色树的版本选择显示 3.30。

## 已接入的 3.30 数据

- **角色天赋和升华**：普通和困难模式的官方 3.30 树及其图标。新构筑默认使用 3.30。旧档可在天赋页「复制并转换」。手术大师按 50% 更少生命药剂回复速度计算；制药大师按 3.30 的药剂类型和消耗条件计算。更新守林人的无束化身持续时间和 3.30 角色升华树皮的减伤、闪避；树皮层数仍由用户按实战填写。部分新节点暂时显示英文。
- **现有宝石**：更新火焰连接、寒冬宝珠、火焰／闪电／巨石魔像、贝达特之契、Transfusion 和 Vaal Sacrifice。火焰连接与寒冬宝珠 1 级和 20 级的伤害值取自公告，其他等级的伤害按现有缩放公式拟合，不能当作游戏逐级数值。Transfusion 的召唤物实际得球由配置决定；Vaal Sacrifice 的资源牺牲只显示在提示中。
- **新宝石**：Arcane Link 和 Fireball of Radiation 可在技能页搜索、计算和保存到本地构筑。两者锁定官方唯一公布的 **20 级、20% 品质**。本地预览 ID 尚不能对应国际服角色 API 的正式 ID。Fireball of Radiation 按不击中的法术火焰持续伤害预览，未假定多个投射物的伤害可叠加，也未假定额外的辅助兼容性。Arcane Link 可在队伍页导出连接效果。
- **现有暗金**：补丁列出的 12 件装备均已更新模板，旧版本保留。多里亚尼腰带可独立选伤害、防御、偷取和药剂四组词缀；模板不预填随机腐化词缀，请用实际掉落装备覆盖。圣徒胫骨可选择 0–4 条不重复的新词缀。新版阿兹里的捷思限制生命回复与补偿，德瑞的舌头在目标受诅咒时才允许非对应伤害造成所选元素异常。
- **新暗金**：新增四件公开样本，见装备库「新物品」。可使用 [Hide of the Vendigo](https://poedb.tw/us/Hide_of_the_Vendigo)、[The Covetous Dark](https://poedb.tw/us/The_Covetous_Dark)、[The Sword of Ages](https://poedb.tw/us/The_Sword_of_Ages) 和 [Dreadmaidens' Sacrament](https://poedb.tw/us/Dreadmaidens_Sacrament) 的公开样本面板。公开单件数值不代表掉落区间；特殊机制的未解析词缀保留在模板中，见下方待验证事项。
- **底材及词缀**：保留前一版的 14 项底材固定词缀更新。火炮箭袋现在只给攻击技能增加 1 个图腾上限，旧装备粘贴文本仍保留原词缀。稀有头盔、戒指和武器的最高阶照亮范围更新为 30%；星团珠宝中小点附加攻速／施速的词缀归入同一族。

角色树来自 [GGG 3.30.0 预览导出](https://github.com/grindinggear/skilltree-export/releases/tag/3.30.0)（提交 `550fb34`）。普通 `data.json` SHA-256：`9686b969bbd744a77f13eeadc57bb71be5032b0ed22be1ee4dbf2025649ccab0`；困难模式 `ruthless.json` SHA-256：`472417a63d8337d26f5708bdac9eee9a04e5fab9a2ecb8ed04a17a04ea4b6b52`。图标采用导出所指定的 0.3835 缩放档。其他数值以 [3.30 补丁](https://www.pathofexile.com/forum/view-thread/4013680)、[宝石公告](https://www.pathofexile.com/forum/view-thread/4013898)和[新暗金公告](https://www.pathofexile.com/forum/view-thread/4013701)为准；样本面板取自上列 PoEDB 页面。

## 异界天赋页签

在任意构筑打开「队伍 → 对比 → 异界天赋」这一排中的「异界天赋」。拖动平移、滚轮缩放，悬停查看节点说明；搜索框可匹配中英文名字和词条，「下一个」定位匹配结果，「查看全图」重置视角。这个页签用于浏览；不分配天赋，不会写入构筑或影响伤害计算。

图的布局、连接和数值以 [GGG 3.30 异界树导出](https://github.com/grindinggear/atlastree-export/releases/tag/3.30.0)（提交 `22607c8`）为准，共 1,116 个图上节点。未发布的新版图标使用通用节点图案；复用的官方图标按资源名匹配。中文对照 [国际服官网](https://www.pathofexile.com/atlas-skill-tree) 与[国服官网](https://poe.game.qq.com/atlas-skill-tree) 的旧版同名节点和相同词条；新增或改动内容标为「3.30 预译」。按住 Shift 可以核对英文原文。查看器、图数据和中文词表随安装包提供，无需联网。

离线生成器是 [atlas.py](../macos-localization/atlas.py)。输入官方 3.30 JSON，以及来自同一旧版本的中英文 JSON 和已核对的预译词表。导出 SHA-256 记录于 `src/Data/Atlas/3_30/tree.json`。当前 `src/Locales/Atlas/3_30.json` 可作为再生成时的 `--extra` 参数；若数值或英文改动，以正式数据重新对照。

## 开服后待核对

本机于 2026-11-12 核对时，国际服客户端仍为 `3.29.3dd`。本分支未取得正式 3.30 客户端表。需要按客户端数据替换本地预览 ID、插值曲线，补齐装备、词缀权重、交易 ID 与掉落等级。异界天赋独立于角色数值计算。

- **赛季独有机制**：没有模拟空手视为爪、Temporal Mirage 与 Moonfall 的触发、永久致盲及全部首领窃取词缀、药剂自损和反击触发；这些效果不应计入比较结果。Putrid Seed 的油与珠宝扩展节点规则也未加入。
- **其余数据**：Wickerman/内脏、佣兵实际生存和输出、新首领、完整词缀池及掉落规则没有进入本版计算。永恒珠宝继续使用已有查表；新节点的所有种子结果未逐一核验。

## 本机验证

- 9 项新增回归覆盖新宝石、伤害曲线端点、守林人树皮、暗金变体、图腾上限和指定药剂效果。
- 通过引擎打开和复制转换 14 份现有构筑，涵盖普通毒瓶、弹跃、四档末日与国服军帽样本。逐一核对节点、专精、升华、装备数据、转换后的可导出内容及原文件哈希。
- 在弹跃红图样本中，生命药剂提示的持续时间由 7.64 秒变为 15.28 秒。引擎计算的持续回复率仍为 1,780.2 生命/秒。
- 核对 16 张图集的尺寸与全部图标坐标。以中文打开天赋、技能、装备及计算视图，计算结果与英文一致。

## 从本地提交构建预览包

按 [macOS 打包说明](../macos-localization/README.md) 准备匹配的 macOS 运行库源码。用 `update.py` 的 `--local-commit` 指定此分支的完整提交哈希，传入 `--port` 和独立的 `--output`。这个参数使用本机 Git 数据。预览包使用单独的构筑目录，可以复制旧构筑进去试用。
