# PoE 1 3.30 本地预览

分支为 `local/poe-3.30`，从本机中文版源码 `4d0ea9113` 分出。角色天赋树使用 GGG 的 3.30.0 预览导出。PoB 的应用版本号仍为 2.67.2，角色树的版本选择显示 3.30。

## 本次支持

- 普通和困难模式的 3.30 角色树，以及匹配的图集。新建构筑默认使用 3.30。旧构筑可以在天赋页用「复制并转换」同时保留两个版本。中文词库对没有译名的节点沿用英文。
- 手术大师的生命药剂回复速度倍率进入计算页和物品提示，持续回复与单次总量分别计算。3.29 树仍使用原来的回复量词缀。制药大师的宝钻药剂暴击伤害加成沿用按装备药剂估算的条件。
- 更新火焰、闪电、巨石魔像和贝达特之契。火焰魔像的增伤沿用原逐级曲线并整体减 5 个百分点，20 级的 24% 增伤与 15% 范围有官方数据。
- 更新 Transfusion 和 Vaal Sacrifice 的已公布效果与提示。Transfusion 的召唤物实际得球数量在配置中按实战填写。Vaal Sacrifice 的资源牺牲目前在宝石提示中展示。
- 更新 14 个常用底材的默认固定词缀，包括灵药手套、异色鞋、逃难短靴和紫晶戒指。构筑里的装备文字仍由存档读取。

GGG 角色树资料来源为 [3.30.0 预览版](https://github.com/grindinggear/skilltree-export/releases/tag/3.30.0) 的提交 `550fb34`。普通 `data.json` 的 SHA-256 为 `9686b969bbd744a77f13eeadc57bb71be5032b0ed22be1ee4dbf2025649ccab0`，困难模式 `ruthless.json` 的 SHA-256 为 `472417a63d8337d26f5708bdac9eee9a04e5fab9a2ecb8ed04a17a04ea4b6b52`。图集使用导出指定的 0.3835 缩放档。三张在官方提交中更新的图集直接采用标签中的文件。

数值来源为 [GGG 3.30 补丁](https://www.pathofexile.com/forum/view-thread/4013680) 和 [宝石公告](https://www.pathofexile.com/forum/view-thread/4013898)。

## 开服后待核对

- Arcane Link 和 Fireball of Radiation 的完整等级表，以及 Winter Orb、Flame Link 的新版伤害曲线。其他新暗金、剩余装备改动、词缀池、佣兵和赛季机制仍待接入或验证。
- 永恒珠宝以现有查表数据运行。已能加载测试样本，3.30 新节点在每个种子下的结果仍需逐项核对。
- 3.30 异界规划可使用 [PoEDB 异界天赋树](https://poedb.tw/us/atlas-skill-tree/)。地图天赋独立于本项目的角色计算。

## 本机验证

- 通过引擎打开和复制转换 14 份现有构筑，涵盖普通毒瓶、弹跃、四档末日与国服军帽样本。逐一核对节点、专精、升华、装备数据、转换后的可导出内容及原文件哈希。
- 在弹跃红图样本中，生命药剂提示的持续时间由 7.64 秒变为 15.28 秒。引擎计算的持续回复率仍为 1,780.2 生命/秒。
- 核对 16 张图集的尺寸与全部图标坐标。以中文打开天赋、技能、装备及计算视图，计算结果与英文一致。

## 从本地提交构建预览包

按 [macOS 打包说明](../macos-localization/README.md) 准备匹配的 macOS 运行库源码。用 `update.py` 的 `--local-commit` 指定此分支的完整提交哈希，传入 `--port` 和独立的 `--output`。这个参数使用本机 Git 数据。预览包使用单独的构筑目录，可以复制旧构筑进去试用。
